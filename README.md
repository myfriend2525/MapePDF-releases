# MapePDF: descargas

Aquí se publican las versiones de **MapePDF**, una app gratuita para Android con 24 herramientas PDF y un escáner de
documentos. Todo funciona en tu teléfono: sin anuncios, sin registro y sin rastreo.

## Descargar

Abre la [última versión](https://github.com/myfriend2525/MapePDF-releases/releases/latest) y descarga el archivo
`.apk`. Necesitas Android 7.0 o superior.

Si ya tienes MapePDF instalada, no hace falta volver aquí: la app avisa cuando hay una versión nueva y la instala desde
dentro (puedes desactivarlo en **Ajustes → Actualizaciones**).
